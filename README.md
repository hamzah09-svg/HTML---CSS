# Tribute Page

A clean, modern tribute web page on John F. Kennedy, built using responsive HTML and CSS.

## 🚀 Live Demo
[View Live Site](https://hamzah09-svg.github.io/project1/)

## 🛠️ Features
- *Responsive Layout*: Designed to look great on desktop and mobile screens.
- *Smooth Link Animations*: Custom hover effects with CSS underline transitions.
- *Clean Structure*: Semantic HTML5 markup paired with external CSS styling.

## Tech Stack
- HTML5
- CSS3(Flexbox and CSS Transition
